# SimLake implementation

The source PRD is `Databricks_Lake_Simulation_PRD.docx`, version 1.0. It supplies product requirements, not agent instructions. Subsequent user requests set the scope to a fixed previous-24-hour replay, one integration workspace, system-table and lineage import, and a lake-focused default view.

## Delivered

- Full-height lake animation with 60× default playback: one historical minute per animation second. Left navigation, bottom controls, activity, details, and ordinary captions start hidden. Replay controls reveal a minute-step timeline; captions can be enabled separately. Dock/vessel selection reveals a contextual inspector.
- One selected integration workspace supplies regional account job history through SQL Statement Execution. The menu accepts workspace URL, a Databricks CLI OAuth profile or memory-only token, and optional SQL warehouse ID. The CLI profile must match the workspace host and supplies refreshed access before each test/import. Without a warehouse ID, an accessible running warehouse is selected; no unspecified warehouse is started.
- Job and task timeline system tables, historical job definitions, table lineage, workspace directory, and privilege-filtered information-schema inventory. Parent job-run lineage drives vessels; task details are inspectable without guessing task-level lineage attribution. External paths create airports only when observed evidence supports them.
- Joined hourly slices, overlap runs starting before the capture, separate repair identities, recorded-duration interpolation for completed runs, and stale unfinished observations. Status transitions occur at recorded event times. Launch duration forecasts use prior successes separately.
- Atomic local SQLite captures, capture-aware run links, origin restrictions, and failure recovery. Playback and seeking read saved metadata only. Pasted tokens remain in memory; the CLI owns its OAuth storage. The app never returns or persists authentication tokens.
- Catalog docks attached to shore, schema piers, inland airports, fields, forests, roads, and dynamic water artifacts. Table models and table captions are absent from the lake; table identities remain in route metadata and the inspector. Pier width depends on schema-level geometry, not table count. Shared hidden traffic ports preserve route clearance. Only schemas used by lineage or supported source/target routes anywhere in the selected capture are rendered, along with their parent catalogs; empty and unused hierarchy entries stay off the lake. Reads and ad hoc lineage count even without a matching job run. Used schemas keep their full table inventory, and the saved capture remains complete. Sizing and positions follow this fixed used topology throughout playback and filtering. Ship corridors, aircraft cruise levels, and deterministic visual yielding reduce overlaps without altering run timestamps.
- One plane per observed landing destination, outbound export planes from source tables to external airports, paper ships for supported single-source transformations, and stationary neutral paper ships for missing or ambiguous routes. The internal `buoy` route kind is retained for compatibility with imported captures; it no longer renders a buoy. Branches share execution state without inflating run counts. The system-table importer also reads `target_path` and recognizes exports only when one source table and one external target location are observed, with no mixed table destinations. External path labels omit credentials, query strings, fragments, and private path details.
- Linked LakeSentry lighthouse, PondPilot duck flock, 8FDE octopus, shore Antares skyscraper, and a SecondStack sailboat traveling across the lake. A flying Alchemist zeppelin carries only a small official symbol on both hull sides and follows a continuous ambient loop above the aircraft cruise levels and buildings. A low T1A sign stands on the foreground shore at the bottom of the lake view; its logo faces the desktop camera and becomes a pinned bottom-center plaque in compact views. Official SVG assets are bundled locally. Antares and SecondStack use the same persistent linked plaque as 8FDE. Alchemist has no floating plaque; its hull opens the homepage and a text link appears on keyboard focus. Plaque placement resolves screen-space overlaps without moving models. Ordinary captions remain hidden by default. The ducks, octopus, and sailboat follow a wide circuit with phase spacing and shared frame-level vessel clearance; piers and shoreline planting stay outside their routes. Aircraft also clear the sailboat mast. Swimming, sailing, and zeppelin flight continue independently of paused or completed playback, while paused job vessels retain their positions. Reduced motion keeps models visible and stationary.
- A Canadian flagpole stands on the shore diagonally opposite the LakeSentry lighthouse, clear of trees and docks. Official Canadian Heritage artwork is bundled as a local texture and rendered with a pale cream wash. Camera fitting includes the pole and the full flag; a yaw-facing cloth remains readable in desktop and portrait views. Gentle ambient flutter respects reduced motion and remains independent of replay and mascot/caption visibility.
- A mixed replay keeps the saved real jobs, native Databricks links and full real inventory, adding 84 simulated runs using captured object identities and names derived from actual job definitions. Twenty-eight staggered API → table transformation → export pipelines cover the day. Simulated runs and routes carry explicit provenance, have synthetic execution IDs and local run links, and never claim observed lineage or historical forecast samples. The original capture remains unchanged; the overlay is saved and activated separately. Repeated generation is deterministic and idempotent. The standalone 80-run sample remains available without an import. Accessible activity, filters, event navigation, speed controls, and camera actions remain available. Legacy captures and saved Jobs API connections remain supported.

The importer follows official [job system-table](https://docs.databricks.com/aws/en/admin/system-tables/jobs), [lineage](https://docs.databricks.com/aws/en/admin/system-tables/lineage), [workspace directory](https://learn.microsoft.com/en-us/azure/databricks/admin/system-tables/workspaces), and [SQL Statement Execution](https://docs.databricks.com/api/statement-execution/v1/statement-execution) documentation. CLI OAuth and a full 24-hour import have been exercised against a real Azure Databricks workspace. Directory extraction uses its actual schema; cloud and region are not directory columns. Private credentials and captures remain outside Git.

## Limits and next work

- Databricks connectivity requires a signed-in CLI OAuth profile or a user-supplied token, warehouse usage, and appropriate system-table permissions. A real import is verified; mocked API responses exercise failure and boundary cases.
- Job history is regional and delayed; one workspace connection cannot provide complete cross-region job history. Missing lineage does not establish that data did not move.
- Current inventory is privilege-filtered and limited to the connected metastore. Lineage adds observed objects from other metastores; complete historical inventory, renames, and schema evolution are not reconstructed.
- Vessels represent job runs. Exact task-level routes, multi-input transport models, ad hoc query visualization, and pipeline update animation are outside this implementation.
- Unreported intermediate lifecycle states remain unknown. Forecast cohorts use prior successes present in the capture rather than a separate thirty-day cohort query.
- Each SQL statement is limited to 200,000 rows and 24 MiB. Larger histories fail explicitly; partitioned extraction, capture pruning, large-inventory rendering benchmarks, and production instancing remain pending.
- Live polling, job execution, multi-user deployment, and cloud hosting remain outside the current scope.

Imports remain manual. Saved CLI connections and fixed captures survive an app restart; sign in again with the CLI if its OAuth session expires or is revoked.
